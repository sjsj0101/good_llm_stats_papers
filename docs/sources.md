# 来源与核验

[返回目录](../README.md)

首轮检索截止 2026-09-09，结合公开网络与维护者本地 EDITH 文献库。发表状态回到 PMLR、ACL Anthology、会议官方页面、OpenReview 的正式决定、JMLR 或期刊出版社核验。

EDITH 共 41,873 条文献记录。本轮为避免本地年份错误导致漏检，对经济学五大刊全部年份的 13,038 条原文和对应摘要做了关键词扫描，缺失路径为零。扫描摘要前删除了元数据，避免把摘要生成模型的名称当作论文内容。此步骤不是逐篇人工全文审读。

主目录 75 条记录中，58 条与官方页面可机器读取的引用元数据进行了比较；17 条通过官方页面内容、正式名单或 PDF 补证。另对 2026 年因果论文、TMLR 和统计期刊样本做了独立复查，并修正 JRSS-B 的在线日期为 2025-09-22。

公开仓库保存论文的公开元数据、原创摘要、方法说明、查询信息和纳入理由。本地原文、索引数据库、完整网页响应、临时日志及电脑路径不随仓库发布。部分 `evidence_locator` 会描述本地读取位置；可公开核查的文献入口由 `official_url` 和 `source_urls` 提供。

本轮按 29 个 venue、145 个年份单元记录覆盖：63 个 partial、82 个 search-only，均未宣称穷尽。多数记录核查至摘要，部分读了正文相关内容；尚未逐篇审计全部证明或复现实验。参见[覆盖与缺口](coverage.md)及[逐条筛选理由](../data/decisions.jsonl)。
